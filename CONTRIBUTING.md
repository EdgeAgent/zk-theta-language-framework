# Contributing to ZK Theta

ZK Theta is currently a design proposal. Contributions should preserve the distinction between implemented behavior, proposed syntax, and illustrative targets.

## Suggested contribution areas

Contributors may improve the language model, runtime semantics, policy model, evidence lineage, evaluation fixtures, diagrams, documentation, or reference adapters. Changes that add syntax should include a short example and explain how the syntax maps to runtime behavior.

## Review expectations

Please keep security and operational claims precise. Avoid presenting simulated or target metrics as measured outcomes. For diagrams, update the Mermaid source first and then regenerate the PNG. For document changes, update the editable source and regenerate the PDF before opening a pull request.

## Pull requests

A pull request should include a concise rationale, affected files, validation steps, and any open design questions. Large changes to policy semantics, memory scope, approval behavior, or tool contracts should be discussed before implementation.
