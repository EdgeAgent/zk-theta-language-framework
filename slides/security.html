TRUST MODEL
Security Boundary
No single primitive guarantees zero knowledge. Verification depends on the formal relation, proof system, witness isolation, and audited implementation.
Component Proposed Primitive Role
Hashing SHA-256 / SHAKE256 Domain-separated policy, transcript, and state digests.
State Commitments Merkle Trees Commit to ordered evidence logs and prove inclusion.
Transition Proof STARK (IOP/FRI) Prove private witness satisfies public state-transition relation.
Identity & Signatures ML-DSA / Ed25519 Authenticate tool manifests, approvals, and receipts.
Confidential Transport ML-KEM Post-quantum key establishment for evidence channels.
IMPLEMENTATION LIMITS
ZK Theta is currently a proposed specification. The reference runner implements hash-linked audit receipts but does not yet include a ZK proof system, verifier circuit, or post-quantum signature stack.
