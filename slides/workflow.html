MULTI-AGENT PIPELINE
SafeRelease Workflow
A reference implementation showing explicit handoffs, evidence collection, and policy-gated promotion.
01
Planner
Turns a release request into an ordered execution plan.
Output
ExecutionPlan {
  checks: ["ci", "sec"]
}
02
Researcher
Collects independent CI, security, and window evidence.
Assertion
assert ci.green
assert sec.pass
03
Verifier
Validates evidence and produces a promotion receipt.
Receipt
VerificationReceipt {
  decision: "eligible"
}
04
Promoter
Performs the action only after a valid receipt and approval.
Policy Gate
await approval
promote.run()
