EXECUTION PIPELINE

Runtime lifecycle

01Declare intent and constraints
02Compile contracts and schemas
03Evaluate policy gates
04Produce execution plan
05Invoke typed tools
06Validate tool results
07Commit evidence to scoped memory
08Emit trace and audit events
09Verify success criteria
10Return receipt and replay record
Design Targets: The framework aims for high policy coverage and typed-tool integrity. These targets guide the reference implementation and evaluation suites.
*Illustrative targets for evaluation planning; not measured production results.
